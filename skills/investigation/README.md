A CEX label does not automatically close a route: inspect a plausible dedicated deposit endpoint within a stated budget. Stop indiscriminate expansion through pooled hot wallets, custodians and service infrastructure.

Keep transfer, infrastructure, account-use, technical-control and ownership claims separate. Never merge wallets merely because they share a funder, service, counterparty, amount, timing pattern or graph category.

For executable tool contracts use [MCP](../../docs/mcp.md), [provider coverage](../../docs/providers.md) and [workspace controls](../../docs/workspace-controls.md). For deliverables use [reporting](../reporting/README.md).

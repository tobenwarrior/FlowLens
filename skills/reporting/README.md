# Reporting skills

After [evidence review](../investigation/audit-trace-evidence/SKILL.md), use [edit-evidence-report](edit-evidence-report/SKILL.md) to write the reader's argument, then [report-investigation](report-investigation/SKILL.md) to export and verify it.

- [Export commands and scope](report-investigation/references/exporting.md) cover Markdown, PDF, DOCX and HTML.
- [Manifest contract](report-investigation/references/manifest.md) defines the existing screenshot-backed document input.
- A clustering conclusion is a reviewed hypothesis with supporting and contrary evidence, not a merged-ownership graph. See the [cluster ledger](../investigation/cluster-wallets/references/hypothesis-ledger.md). Use existing manifest sections/tables; do not invent a `clusters` field.

Include exact evidence, source URLs, coverage, claim status and privacy-reviewed screenshots. Keep real bundles local and preserve input hashes. The [200-line / 25 KiB rule](../README.md) applies to entries and references alike.
